# war-game（暫名）

中古魔法世界的手機即時戰略遊戲（iOS／Android）。你要讓農民採集資源、訓練軍隊，攻下地圖上的城鎮，再決定要掠奪還是治理。法師是戰場上最強的兵種，但也可能陣亡。
