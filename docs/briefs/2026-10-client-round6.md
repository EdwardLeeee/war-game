主旨：war-game-client 做第六輪的畫面：點編隊就是軍團畫面、拿掉分出、資訊欄收起鍵、取消即堅守、新兵自動會合、自動訓練的按鈕。依據是使用者 2026-10-04 的回饋（D-054）。

## 目標

- 使用者點一下編隊按鈕，就能看到並指揮那個軍團。
- 進攻時資訊欄不擋視野。
- 「取消」的意思一致：取消進攻或撤退，兵就停在原地堅守。
- 新訓練的兵會自己走去和部隊會合。
- 使用者不用一名一名點造兵，只決定哪棟暫停。

## 範圍

### 要改（`client/`）

1. **軍團畫面**
   - 點一下編隊按鈕：選取這個軍團，下面顯示軍團畫面，取代一般的選取資訊。
   - 軍團畫面包含：三種兵各一列（現有、目標、−／+）、進攻、撤退、堅守、「照目前選的兵」「清空」「自動補兵」。
   - 原本的長按、點兩下跳過去：你決定要不要保留，寫在 PR 描述。
2. **拿掉「分出 N 名」**，連同「改選其餘 M 名」。
3. **資訊欄收起鍵**
   - 選取資訊（包括軍團畫面）有一顆收起鍵，收起後只留一條細的標題列，再按展開。
   - 收起的狀態記在這一局；換選取時照舊收著。
4. **取消即堅守**
   - 撤退中的兵，再按「撤退」：停下來，改成堅守。
   - 按了「進攻」之後，在選位置的狀態按「取消」，或進攻中再按「進攻」：停下來，改成堅守。
   - 長按輪盤的同一顆也一樣。
5. **新兵自動會合**
   - 先查清楚現在為什麼沒有走過去：是被補進的編隊已經滿了、還在等湊滿 3 名或 20 秒，還是有 bug。
   - 在 PR 描述寫出原因，然後修到「新兵會自己走到部隊所在的位置」。
   - 補不進任何編隊的新兵要去哪裡，提一個做法給我核准再做。例如去人最多的軍團，或留在集結點。
6. **自動訓練的按鈕**（等 core 的 PR B 有協定之後）
   - 兵營、射場、法術營的面板有「自動訓練：開／暫停」。
   - 主城的面板可以調預留額。
   - 人口滿了停下來時，資源列或訊息列提示「人口滿了，蓋民居」。

### 不做

- 自動訓練的規則本身、地圖：war-game-core。
- 正式介面：第三階段。原型的介面照前幾輪的做法，不先出設計稿。
