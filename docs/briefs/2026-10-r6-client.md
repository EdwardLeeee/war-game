## 範圍（`client/`）

1. **兩種風格**：
   - A 銅木是預設，B 墨漆金線在「選單 → 設定 → 介面風格」切換（R6-20）。
   - 切換的選擇記在這支手機上；讀不到就用 A。
   - 兩種排版完全一樣，只換風格：建議用 CSS 變數，照 themes.css。
2. **盤點的 146 項照設計稿做**。拿掉「原型介面（非正式設計）」標示（INV-16）；量測面板（INV-128）樣子不改。
3. **D-087 的新行為**（規則照 spec.md 的表）：
   - 左邊：
     - 平常只有「地圖」鈕。
     - 有閒置村民才出現閒置鈕。
     - 小地圖是方形、112×112，按地圖鈕才打開；進攻、撤退選位置時自動打開，選完自動收回。
     - 打開時，點小地圖跳過去、長按叫部隊前進、撤退點小地圖都照舊能用。
   - 全體回城：
     - 敵方的兵（不含城鎮民兵）打到我方主城 12 格內的建築或村民時，跳出紅底的「全體回城」；最後一次被打 15 秒後收回。
     - 只提醒，不會自己叫村民回城。按了變「回去工作」。
     - 選單裡一直有。
   - 地圖收著時被攻擊：地圖鈕閃紅並顯示幾處；打開後由小地圖上的紅圈閃。
   - 重設鈕拿掉：
     - ✕ 改成「回到什麼都沒選」：取消選取、離開選位置、收掉建築預覽、關建造選單和輪盤。
     - 放建築的提示列加「取消」。
   - 攻下城鎮的對話框：只有一個「留守 − N + 名」，選搶或治理都用這個數字。預設照 D-084：小鎮 1、大城 3，扣掉已經留守的。
4. **玩家色**：甲，藍 #3f7fe0、紅 #d9433a、黃 #e8c42e、紫 #9a5ce0，中立 #d8d2c0。介面和兵、建築的玩家色層都用這組。
5. **字**：iPhone 內建的字，只用 400、700 兩種粗細，不放字型檔進遊戲。
6. **動畫**：照 R6-25 的分鏡和 GIF。閃的東西都要有「減少動態效果」的版本。
- **不改模擬**：
  - 全體回城的觸發要分出攻擊的是敵方玩家的兵還是城鎮民兵，現在的 `attacked` 事件只有位置和被打的目標。
  - 從快照判斷不準的話，回報 ceo，由 core 在協定裡加欄位，不要自己改 sim/。
- 菱形地圖（#213）和 3D 兵種、建築照原本的 brief（`2026-10-art-in-game-client.md`）做，順序由你提。
