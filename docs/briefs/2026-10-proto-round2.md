## war-game-core 的範圍（`sim/`、`sim.yml`）

1. **時間上限改成開局參數**
   - 0 代表沒有上限。
   - 玩家對電腦預設 0。
   - AI 對 AI、確定性檢查、headless 預設 36,000 tick，和現在一樣。
   - 這會改到協定，先開介面 PR（`sim/PROTOCOL.md` 加 `protocol.ts`），通知 client。
2. **電腦的時間規則**
   - 第 20／22／24／26 分鐘這些規則，只在有時間上限的對局使用，而且要改成依「離結束還剩多久」來算。
   - 沒有上限時，換成不依賴結束時間的做法，例如兵數或存款到一定程度就總攻。
   - 不可以在某個固定時間派一小隊兵去送死。
   - 第十輪的結果（C 版本等）一起併進來。第十輪不再單獨開 PR。
3. **簡單難度**
   - 開局參數，至少要有「簡單」和「普通」。普通就是現在的電腦。
   - 簡單只能限制電腦自己，不能給普通任何加成。可以限制的例如：
     - 農民目標數
     - 兵營、射場的上限
     - 第一次去打野城的最早時間和兵數
     - 進攻門檻
     - 要不要派農民去晶脈
   - 數值由你提出，在 PR 裡列「項目 → 簡單 → 普通 → 理由」，我核准後寫進 GDD 第 13 節。
   - 目標：
     - 使用者在正常速度下，大約前 12 分鐘能先拿到一座野城。
     - 電腦第一次打你的主城，比普通晚得多，而且兵少。
     - 送 CI 之前，先在本機用「電腦對不動的玩家」量時間軸，和我量普通的方法一樣（`--ai 0,1`）：
       - 第一次打野城在第幾分鐘、帶幾名兵
       - 第一次出兵打主城在第幾分鐘、帶幾名兵
       - 第幾分鐘攻下主城
4. **蓋建築自動派農民**
   - `build` 指令可以不帶農民，由模擬依固定規則挑農民。
   - 挑選的規則：
     - 離建築最近的農民優先，平手依 ID。
     - 不挑玩家親手派去待命的農民（GDD 第 4 節）。
     - 不挑正在蓋別的建築或正在修理的農民。
     - 不挑躲在建築裡的農民。
   - 派幾名依建築大小決定，由你提出。
   - 蓋完交給經濟分配。
   - 挑不到農民時，照協定現有的方式拒絕，讓畫面可以提示。
   - 要能重播、要有確定性。
5. **路被擋住時改打擋路的建築**
   - 情境：有明確攻擊目標，或正在前進，但目標被建築完全堵住、走不到。
   - 做法：改打擋路的敵方建築，不要卡在原地。
   - 測試：
     - 用民居把主城圍死，攻方要打穿進來。
     - 路只是變窄、沒有堵死時，照舊繞路。
   - 之後的城牆也要用這條規則。
6. **驗收**
   - 以上每項都要有單元測試，而且拿掉改動時測試會失敗。
   - 100 局 AI 對 AI（普通對普通，有 30 分鐘上限）照現有門檻：
     - 出生點勝率 35–65%
     - 重播 0 失敗
     - 平手 ≤25%
   - 另跑一組「普通對簡單」，普通的勝率要明顯比較高。門檻由你提出。
   - 回報 CI 時，依 head SHA 列出全部 run。

## war-game-client 的範圍（`client/`、`client.yml`、`pages.yml`）

1. **速度**
   - 慢、正常、快是每秒 20、30、40 個 tick，預設「正常」。
   - 量測頁照舊用固定的 tick 速度，要在結果裡寫明用的是哪一個。
2. **開局畫面**
   - 加難度選擇：簡單、普通。
   - 玩家對局不設時間上限，等 core 的介面 PR 合併後接上。
3. **重設按鈕**
   - 固定在畫面上，觸控範圍至少 44 pt。
   - 按一下就做完這些事：
     - 取消選取（`clear`）
     - 離開放建築、晶砲、撤退、集結點的狀態
     - 關閉面板
   - 原本的 ✕ 可以留著。
   - 放在哪裡由你在原型的版面裡決定，不要擋到小地圖、指令區和編隊按鈕。
4. **分出 N 名**
   - 選取資訊裡可以用 +／− 或輸入數字，從目前選取的部隊分出 N 名。分出來的就是新的選取，可以存成編隊。
   - 挑哪 N 名的規則由你在計畫裡提出，例如離部隊中心最近的，或依兵種比例。寫進 GDD 第 10 節的對照表。
5. **蓋建築不用先選農民**
   - 沒有選農民時，也要能打開建造選單，例如從主城面板或一顆固定的建造按鈕。
   - 放好、按 ✓ 後，送出不帶農民的 `build`。
   - 被拒絕時（挑不到農民），提示「附近沒有可以派去蓋的農民」。
6. **不做**：
   - 城牆、城門、箭樓、分城、士兵躲進建築：第三階段。
   - 正式介面：R6 由 war-game-ui 出設計稿。
7. **驗收**
   - 手勢對照表更新到 GDD 第 10 節的新列。
   - e2e 的主要流程加這幾步：
     - 選難度
     - 用重設按鈕離開放建築的狀態
     - 分出 N 名存成編隊
     - 不選農民蓋民居
   - 回報 CI 時，依 head SHA 列出全部 run。

## 流程與限制

- 先把計畫回給 ceo（不用 plan mode），核准後才開始。
- core 先開介面 PR（時間上限、難度、不帶農民的 `build`），client 照它接。
- 這一輪的每個 PR 都會改變試玩版本。
  - PR 描述第一行要註明「會改變試玩版本」。
  - 合併時機由 ceo 決定。整輪做完、上線後，ceo 才通知使用者一次新的版本號。
- 本機只跑相關的測試，重工作用 `systemd-run --user --scope -q -p MemoryMax=1500M -p MemorySwapMax=0` 包起來，available 低於 2 GB 就等。
