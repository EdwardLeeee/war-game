主旨：war-game-client 讓玩家可以選隨機地圖：開局畫面加「固定地圖／隨機地圖」，隨機地圖上只畫探過的地方。依據是 D-074 和 core 的隨機地圖 PR #172。合併要等 war-game-ai 的偵察 PR（電腦不再偷看）合併以後。

## 目標

- 開局可以選固定地圖（照現在）或隨機地圖。
- 隨機地圖上，玩家開局只看得到自己家附近；城鎮、資源點、岩石、敵方主城探到才畫出來。
- 固定地圖的畫面和操作完全不變。

## 依據

- D-074：
  - 使用者選「1b」（出生角落和城鎮也隨機）、「什麼都要探（像世紀帝國）」、地圖 129×129。
  - 使用者也要保留固定地圖：「不過可以保留現有地圖，這樣我才知道ai強弱」「不然我根本不確定ai到底變強了沒」。
- core 的 PR #172（main e78e742；`sim/PROTOCOL.md`，PR 描述裡「給 client 的」那一節）：
  - `init.map`：`"fixed" | "random"`，沒給就是固定地圖。`MapInfo.mode`，`LogHeader.map`。
  - 隨機地圖的 `ready.map`：`terrain` 全是空地，`spawns` 只有自己（要用 `player` 找），`towns` 是空陣列。
  - 城鎮從 `view.towns` 來，探到才有，位置看 `TownField.cellX`、`cellY`、`size`（`TOWN_STRIDE` 14）。
  - 岩石從 `view.placement` 的 Blocked 來，隨機地圖只標探過的格子。資源點從 `view.nodes` 來。
  - `worker.ts` 現在會拒絕「有人類玩家的隨機地圖」。war-game-ai 的偵察 PR 會拿掉這個限制（brief `docs/briefs/2026-10-ai-scouting.md`）。

## 範圍（`client/`）

1. **開局畫面**：加「地圖」選項，固定地圖（預設）、隨機地圖。
   - 寫清楚差別。例如固定地圖：「每局同一張，適合比較電腦強弱」；隨機地圖：「每局不同，只看得到自己家附近」。
   - 記住上次的選擇。
2. **隨機地圖的畫面**：
   - 地面、岩石、森林、資源點、城鎮、敵方建築，都只畫探過、看過的。沒探過的地方畫成一看就知道「還不知道」的樣子，和迷霧（探過但現在看不到）分得出來。
   - 小地圖一樣只畫探過的地方。
   - 城鎮提示等用到城鎮位置的地方，改用 `view.towns`，沒探到的城鎮不能出現。
   - 開局鏡頭對準自己的主城。
3. **對局紀錄**（D-056）：紀錄要記下地圖模式，重播要用同一種地圖。
4. **測試頁**：可以選隨機地圖跑電腦對電腦。

### 不做

- 地圖產生器、協定：war-game-core。
- 電腦的偵察：war-game-ai。
- 正式介面和正式美術：第三階段。

## 限制

- 公開 repo：不放金鑰、個資或真實姓名。
- 本機只跑相關的測試；Playwright 用 `systemd-run --user --scope -q -p MemoryMax=1500M -p MemorySwapMax=0` 包起來，available 低於 2000 MB 就等。完整 e2e 交給 CI。
- 要 rebase 疊著的分支時，不強制推送，改推新分支、開新 PR（使用者 2026-10-07）。
- PR 會改變試玩版本，描述第一行寫「會改變試玩版本」。合併時機由 ceo 決定。
- 使用者指示（2026-10-03）：你自己 terminal 每個回合的結尾文字一行就好；給 ceo 的訊息只在三種時候傳：計畫要核准、PR 好了、需要決定的事。
