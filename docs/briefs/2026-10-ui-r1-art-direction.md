主旨：war-game-ui 做第 1 輪「畫面風格」。畫出至少三種精美的風格，每一種都要證明做得出整套素材，讓使用者挑一種當整個遊戲的美術方向。

## 目標

使用者要能看到至少三種風格，每種都有：
- 一張手機橫向的戰鬥畫面
- 一個法師的完整動作動畫
- 一段量產說明

看完之後，使用者挑一種當作整個遊戲的美術方向。

## 依據

- 使用者裁示（2026-09-30，詳見 `docs/decisions/log.md` D-001～D-011）：
  - 美術：「我待會開一個uiux session 叫他來設計，我們要有自信我們可以做出很精美的畫面」
  - 世界觀：「我覺得我們可以設計成有魔法的中古世界，魔法師很強但不是不會死，可以打城鎮aka資源點，可以選擇搶或是治理這樣」；之後補充「我希望像中國五代十國那樣亂，但像幼女戰技那樣有魔法」，選「東西方並存」、法師「不會飛」（D-009、D-010）
  - 類型：即時戰略（「a比較好玩」），手機橫向，第一版單機對電腦 AI，最多 4 方混戰（D-011）。
  - 美術來源：使用者沒有選「買現成素材包」「AI 生圖工具」「找美術外包」，而是交給這個 session 設計。
    所以預設不花錢、由我們自己做。某個選項需要付費工具時，先回報 ceo。
- 使用者的出圖偏好，已寫成 design-review-rounds 技能，照它做：
  - 先畫出選項，再請使用者選。
  - 每個選項一張圖，檔名與圖內標籤用「輪次-項目-選項」。
  - 另附總覽對照圖。
  - 用圖片檢視器開給使用者看。
  - 對使用者說明用白話。
- 引擎還沒定，候選見 `docs/research/2026-09-engine-candidates.md`：
  - 兩個候選在遊戲執行時都只畫 2D 圖片，3D 可以當製作工具。
  - 如果某個選項必須即時 3D，要在說明裡標清楚，因為它會多一輪 3D 引擎實驗。

## 世界觀重點（出圖用）

完整設定在 `docs/world/bible.md`，規則在 `docs/design/gdd.md`，出圖前先讀。重點如下：

- **東西並存的亂世**：
  - 使用者 2026-09-30：「我希望像中國五代十國那樣亂，但像幼女戰技那樣有魔法」，並選了「東西方並存」。
  - 大帝國崩潰後，東陸的節度使和西陸的諸侯各自稱王，最多四方同時混戰。
- **兩套外觀**：
  - 東陸是中國古代風：城池、城樓、槍陣、弩、具裝騎兵、霹靂車。
  - 西陸是西方中古風：石堡、長矛、長弓、騎士、投石機。
  - 兩套要在同一種畫風裡統一，放在同一個戰場上不突兀。
- **兵種定位**（兩邊相同，名字與外觀不同）：

  | 定位 | 東陸 | 西陸 |
  |---|---|---|
  | 農民 | 農夫 | 農民 |
  | 槍兵 | 槍兵 | 長矛兵 |
  | 遠程 | 弩手 | 長弓兵 |
  | 重騎兵 | 具裝騎兵 | 騎士 |
  | 攻城砲 | 霹靂車 | 投石機 |
  | 法師 | 術士 | 晶術師 |

- **四個國家**：北朔（狼首）、南溟（白鶴）、布倫莫爾王國（雙塔）、塞勒斯同盟（帆船）。
  括號裡是旗幟圖樣，要在小尺寸下認得出來。玩家顏色另外選，只換旗幟與披風的顏色。
- **法師**（使用者：「魔法師很強但不是不會死」；選了「不會飛」）：
  - 法師是正規軍的精英兵種。東陸用法印、西陸用晶杖當法器。
  - 平常連發晶彈，像步槍；大招晶砲要原地校準，像砲擊，落點會有預警圈。
  - 身上有半透明的防護罩，被擊中時會閃爍，被打破時會碎裂。
  - 法師不穿鎧甲，罩一破就很脆弱，要看起來強大又脆弱。
- **城鎮**：
  - 地圖上有中立的自由城鎮，外觀跟著所在地區，東陸就是東方風，西陸就是西方風。
  - 打下來可以選擇搶（變成焦黑的廢墟）或治理（插上旗子、修繕、穩定產出）。
  - 四種狀態要一眼分得出來：中立、廢墟、我方治理、敵方治理。
- **資源**：糧食、木材、金幣、魔晶，再加上人口上限。
- **色調**：整體要有亂世戰爭的緊張與壯觀，但不血腥獵奇。要明亮一點還是偏暗，交給你在不同選項裡探索。

## 每個選項的戰鬥畫面要有

- **尺寸**：iPhone 14 Pro Max 橫向，932×430 pt，要畫出動態島與圓角的安全區。
- **場景**：
  - 我方主城一角
  - 農民在砍樹或挖金礦
  - 一座城鎮（四種狀態之一）
  - 東陸軍對西陸軍交戰，這樣一張圖就能看到兩套外觀；槍兵、遠程、重騎兵、攻城砲都要出現
  - 我方法師正在發射晶砲，畫面上要有預警圈和防護罩
- **操作介面初稿**：
  - 資源列
  - 小地圖
  - 選取資訊與指令區
  - 閒置農民按鈕
  - 編隊 1–4
  - 全軍按鈕
  - 暫停鈕
  - 位置和細節第 2 輪再修，這輪只要風格一致。
- **可讀性**：RTS 在手機上單位很小。
  - 每個兵種在實際縮放下都要一眼認得出來（靠剪影和顏色），敵我分明。
  - 每張圖要標出單位的實際高度（pt）。

## 驗收條件

- [ ] 至少 3 個風格選項（`R1-01 畫面風格` 的 A、B、C…）。至少一個是純 2D，至少一個是「先做 3D 模型、再算成 2D 圖」（世紀帝國二的做法）。
- [ ] 每個選項都有三樣東西：
  - (a) 上面規格的橫向戰鬥畫面設計稿。
  - (b) 用該選項的製作流程，把法師（東陸或西陸任選一邊）做完整：待機、走路、發射晶砲、防護罩碎裂後倒下，輸出成 GIF。至少一個方向；流程如果能自動產生 8 個方向，另附 8 方向合成圖。
  - (c) 量產說明，內容包括：
    - 工具鏈
    - 總素材量：東陸、西陸兩套，各約 6 兵種 × 4 動作 × 8 方向、約 13 棟建築、城鎮四種狀態，加上兩種地貌；玩家顏色用程式換色，不用每色重畫
    - 每件大約的工時
    - 對引擎的需求（2D 圖片或即時 3D）
    - 所有工具與素材都可以商用的確認
- [ ] 標籤與檔名：
  - 檔名用 `R1-01-畫面風格-<字母>-<名稱>-mobile.png`，圖內左上角印同一個標籤。
  - 總覽圖是 `R1-99-總覽對照.png`。
  - GIF 用同樣的命名規則。
- [ ] 呈現給使用者：
  - 先在對話裡列出「檔名 → 選項」清單。
  - 再用 `eog --new-instance` 把總覽和所有選項開在同一個視窗，記下 PID。
  - 看完後用記下的 PID 關掉視窗。
- [ ] 重現：mockup 程式、模型、腳本等原始檔都放在 `design/round1/`，README 寫明怎麼重新產生每張圖。
- [ ] 回報：使用者的選擇與原話回報給 ceo。

## 限制

- **原創**：不仿製世紀帝國、魔獸爭霸、星海爭霸或任何作品的角色、建築、介面，也不用幼女戰記的任何元素（App Store 4.1、5.2.1）。
- **授權**：第三方字型、材質、模型只能用可以商用的授權，記下出處與授權。
- **工具**：要能在這台 Linux 機器上跑（顯示卡是 Intel UHD Graphics 620），或在 GitHub Actions 上跑。
  需要安裝的軟體（例如 Blender）先列在計畫裡。
- **公開 repo**：不用使用者真名，不放金鑰。大型二進位原始檔（例如 `.blend`）先回報大小，由 ceo 決定要不要用 Git LFS。

## 回報方式

1. 先把計畫回給 ceo（不用 plan mode）：每個選項的方向與製作流程、要安裝的工具。ceo 核准後才開始做。
2. 用 `scripts/dev-worktree.sh ui design/r1-art-direction` 建自己的 worktree。出圖後直接開給使用者看，同時開 PR。
3. 需要使用者決定的事（出圖之外的），回報 ceo。
