# Brief：種田農民的鋤頭和動作（R16）— war-game-ui

ceo 2026-11-10。

## 背景

- 使用者原話（2026-11-10）：「種田的農民圖看起來好像有點怪」。
- ceo 從正式版（art-v7.6）抽出 `work_farm` 每一格給使用者看：放大 3 倍的幾格、東陸和西陸各一張全部方向。圖不在 repo。
- 使用者在選擇欄位選了兩個選項，另外打了一句：
  - 「鋤頭太大太白」：刃跟上半身一樣大、又亮又白，舉起來像舉牌子，落地像一塊白板。
  - 「動作怪」：舉得太高過頭，刃落地後平躺著拖。
  - 自己打的：「手拿鋤頭感覺不太符合真實拿法」。
- 和以前裁示的關係：D-029（2026-10-01）使用者選了「P2-06 農民工具 B 放大」，因為工具太小、在遊戲裡看不清楚。這次的話很明確，不用再問要不要改。新稿要讓使用者自己比較「看得清楚」和「像真的」兩邊，選好後 ceo 在決策紀錄寫明取代 D-029 鋤頭的部分。

## 程式裡的現況（`design/production/blender/anims.py`）

- 鋤頭在 `_tools()`：
  - 柄長 1.43 m。
  - 刃 `box(... (0.34, 0.40, 0.045), steel ...)`：34 × 40 cm，厚 4.5 cm，用兵器的 `P["steel"]`。
  - 刃往柄折 40 度，讓待機時平躺在地上、正面朝鏡頭。
- 「太白」是材質問題，不只是太大。農具是暗色、用舊的鐵，同一個函式裡已經有 `tooliron_p2`。
- 同一把鋤頭出現在很多動作裡，改了全部都要重算：
  - 東陸、西陸的 `work_farm`。
  - 西陸農民平常拿的就是鋤頭（`"axe" if kind == "farmer_e" else "hoe"`）：待機、走路、攻擊、倒下。
- 動作 `WORKS["work_farm"]`：手舉到大約 1.36 m，刃朝上（像舉牌子），再落下、平躺著往回拖。

## 要做的

1. **先查資料再畫**：
   - 東陸照唐末五代，依使用者的規則，不要日式。查文物和壁畫，例如：
     - 敦煌莫高窟第 23 窟〈雨中耕作〉、第 445 窟彌勒經變裡的耕作。
     - 榆林窟第 25 窟的耕作圖。
     - 唐代出土的鐵钁、鐵鋤。
   - 西陸查中古歐洲的鋤頭和用法，例如 Luttrell Psalter、Très Riches Heures 這類手抄本的農事圖。
   - 要查清楚的有：刃的形狀、大小、顏色，刃和柄的角度，柄長，兩手怎麼握（後手、前手各在哪裡），舉多高，怎麼鋤下去、怎麼往回拉。
2. **鋤頭至少兩個選項**，兩國各畫：
   - A：照真實大小、暗色鐵。
   - B：比真的大一點，讓遊戲裡看得清楚，但形狀、顏色照真的。
3. **新動作**：
   - 照查到的真實拿法和用法做。
   - 第一格和最後一格要等於該農民自己的待機姿勢，包括拿工具的手。
   - 每一格排開看過再交。

## 交給 ceo 的稿（R16，檔名照「輪次-項目編號-項目名-選項字母-選項名-裝置」，圖內左上角印同一標籤）

- **R16-01 鋤頭**：每個選項一張。
  - 一邊是遊戲裡的實際像素大小：x3，站在農田上，放在 iPhone 932×336 的畫面裁切裡，旁邊放一名槍兵比大小。
  - 另一邊放大 3 倍。
  - 另外加一張總覽對照圖，含現在的樣子。
- **R16-02 種田動作**：兩國各一張關鍵格，另附 GIF。GIF 要有實際大小和放大兩種。
- **R16-03 西陸農民拿鋤頭待機、走路**：同一把新鋤頭在平常動作裡的樣子。不放的話，使用者核准了種田，卻會在農民走路時看到另一個樣子。
- 參考資料另做一張圖，標出處，給 ceo 看依據。用到的圖片要確認授權，不放進 repo。

## 流程

1. 先回計畫給 ceo，不用畫：查到的資料和出處、真實的拿法和動作（用文字寫）、選項、預估時間。
2. ceo 核准後才畫，畫好交 ceo。ceo 給使用者看並問選哪個。
3. 使用者核准後，下一版美術包（art-v7.7 之後）照核准的稿重算。
   - #452 的 art-v7.7 改釘還在等使用者在 iPhone 上量 10 分鐘，這件事不要趕著發新版來取代它。
   - 正式版只有在 client 改釘美術包之後才會變。
