# Brief：R7 寫實畫風比較（D-092）— war-game-ui

ceo 2026-10-20。依據：`docs/decisions/log.md` D-091、D-092。

## 背景

- 使用者 2026-10-20：「我們的模型比很久以前的星海爭霸 世紀帝國都還要簡陋，我認喂這樣的作品是完全沒辦法賺錢的。我希望你在行動以前多去看看人家3d遊戲」。
- ceo 的研究結論（研究報告：`/home/oraclelee/Desktop/war-game-worktrees/research/reports/手機 3D 策略遊戲 美術與引擎.md`）：
  - 星海爭霸、世紀帝國二、AoE2 DE、部落衝突也都是先算好的圖，方法和我們一樣。
  - 差距在每個模型背後的美術工序：概念設計、雕刻或細緻建模、貼圖、逐個打光、在實際大小下檢查。
  - 你的自評：我們的模型沒有任何貼圖、UV 或法線圖。
- 使用者的選擇：
  - 引擎：「先不換，美術補齊再說」。three.js 試驗頁取消。
  - 風格：「完全寫實比例」，比例照真人，不誇大。
  - 第一步：「都交給你來做設計」，由 ceo 設計。

## 這一輪要回答的問題

在不花錢、不用使用者開帳號的前提下，用專業素材加上正確的工序，寫實比例的兵和建築在手機實際大小能做到多好？哪一條來源值得繼續？

## 要做的東西

同一組內容做成幾個版本，並排比較：

- 東陸槍兵、東陸弩手：idle、walk、attack 三個動作。
- 兵營。
- 一塊 12×8 格的地面：草、土路、碎石、一小段河岸。

| 版本 | 做法 |
|---|---|
| 0 現在 | art-v4 原樣，當對照 |
| 1 現在的形狀＋寫實工序 | 兵改成寫實比例（頭約身高 1/7.5）。展 UV，貼寫實 PBR 材質（Poly Haven、ambientCG 的 CC0：布、皮、鐵、木、石、灰泥、茅草）。拿掉描邊，加主光、補光、輪廓光和環境光遮蔽。建築加倒角、石縫、木紋、髒污 |
| 2 寫實人體底模 | 用授權允許商用的寫實人體產生器（例如 MakeHuman／MPFB，先確認授權）做寫實比例的身體，再加盔甲、衣服、武器，貼 PBR 材質。動作用 CC0 或可商用的動作庫（例如 Quaternius 的動作庫、CMU 動作捕捉），重新對到骨架 |
| 3 AI 生成 | 用不需要帳號、輸出可商用的 AI 3D 模型（例如 Hunyuan3D 2.x 的公開試用頁），從我們自己畫的概念圖生成槍兵、兵營。再修整、綁骨架、套版本 2 的動作 |

- 地面三個版本共用：寫實的 CC0 貼圖混合，加上筆觸、碎石、草叢。版本 0 用現在的格子。
- 打光三個版本都一樣，相機照舊是方形斜看。

## 規則

- **授權**：
  - 每一樣外部素材，使用前先讀官方授權原文，記在新建的 `THIRD_PARTY_NOTICES.md`（來源、授權、網址、日期）。
  - 只用可商用、可以算成圖片出貨的。授權不清楚就不用，回報 ceo。
  - 不用 TRELLIS（它依賴的 nvdiffrast 限非商業使用）。
  - 不用 Synty 的模型做 AI 生成。
- **不花錢、不開帳號**：需要付費或登入的工具一律不用。覺得值得付費的，寫在報告裡讓 ceo 問使用者。
- **原創**：不照抄任何遊戲的兵或建築造型。概念圖自己畫，可以參考真實的中世紀與東方甲冑。
- **檔案**：
  - 外部素材的原始檔不進 repo。CI 照網址下載，核對 sha256。
  - 算出來的比較圖可以放 `design/r7/out/`。

## 交付

1. 每個版本一張圖，檔名照慣例，例如 `R7-01-寫實-1-現在形狀加工序-mobile.png`。內容：
   - 手機 3 倍和實際大小（31 pt）各一份；
   - 兩種兵並排、兵營、地面；
   - 我方藍和敵方紅各一，看陣營分不分得出來。
2. 一張總覽：4 個版本並排，實際大小。
3. 每個版本一個 GIF：walk 和 attack。
4. 每個版本的代價：
   - 要做完 12 種兵、14 種建築、城牆、資源點、地形要幾天；
   - 圖集記憶體（3 倍未壓縮、2 倍 ASTC）；
   - 授權的限制。
5. 你的評語：哪一版最接近「寫實細緻」，實際大小下好不好認。
6. 給 client 的測試圖集，格式照 art-vN，發成 Release `style-test-1`（只放可公開的素材），讓 client 在手機頁上並排播放。

## 不做

- 不改遊戲裡正在用的圖。art-v5（地形）照原計畫給城牆和障礙物那一批用。
- 不做 glTF 和 three.js。

## 流程

- 先回 ceo 計畫和時間估計，核准後才開工。
- 卡在授權或做不到，先回報 ceo，不要自己換做法。
