# Brief：野城加城牆（D-089）— war-game-core

ceo 2026-10-19。依據：`docs/decisions/log.md` D-089。

## 背景

- 使用者看過 R6-06 野城的兩個選項（牌坊、房子圍廣場），都不選，原話：「希望像一個城堡」。
- 追問後的裁示：
  - 城牆真的擋路，只能走城門。
  - 小鎮用木柵，大城用石牆。
  - 城門一直開著，誰都能走。
- ceo 定的細節：
  - 牆只擋走路，不擋射擊。遠程兵、法師、箭樓都可以隔著牆打。
  - 牆不會壞，廢墟時也照舊在。
  - 城鎮範圍改成「牆以內」。
- war-game-ui 畫選項圖，使用者核准後才實作。計畫和格子可以先談。

## 格子（war-game-ui 的提案，要和你對過）

- 牆是一圈正方形，厚 1 格，圍起來的面積和現在的圓圈差不多：
  - 小鎮：牆在距中心第 5 格，裡面 9×9＝81 格（現在約 79 格）。
  - 大城：牆在箭樓外第 7 格，裡面 12×12＝144 格（現在約 154 格）。箭樓照舊在中間。
- 四個門開在十字街碰到牆的地方。
  - 小鎮的門和街一樣寬。
  - 大城的門 2 格寬，兩邊各 1 格是城樓的墩子；四角各一座 2×2 角樓。
- ui 會畫一張俯視格子圖給你對。對不上的地方，和 ui 直接談；談不攏，回報 ceo。

## 先回 ceo 的計畫（簡短）

1. **牆和門怎麼進模擬**：
   - 占格和尋路怎麼做。
   - D-024「路被擋住時改打擋路的建築」對城牆怎麼辦：牆不會壞，兵不能卡著打牆。
2. **城鎮範圍改成牆以內**，連帶要改的地方：
   - 攻下的條件、治理。
   - 民兵和駐軍站的位置、躲進去。
   - 蓋箭樓的範圍（D-061）、搶的留守（D-084）。
3. **地圖**：
   - 固定地圖和隨機地圖都要確認：牆不壓到資源點、出生點和路。
   - 不能把任何地方完全堵死。
4. **電腦**：
   - 尋路照模擬走。
   - 電腦的判斷要不要改（例如估強弱、集結點在牆外），列出來。交給 war-game-ai 的部分寫清楚。
5. **協定**：client 要畫牆、點選，需要哪些新欄位。
6. **量測**，都和 main 比：
   - 主動四組。
   - 電腦對電腦：平手、出生點、局長、打城的時間和傷亡。
   - 思考時間和每 tick 時間。

## 流程

- 從 origin/main 開新分支。PR 第一行寫「會改變試玩版本」。
- 改模擬會讓存著的局接不下去。
  - 合併時機由 ceo 定。
  - 盡量和 D-086 的 A3、#223 排成同一批上線，只斷一次。
- 回報 CI 時，依 head SHA 列出全部 run。
- 數值一律從 `rules()` 讀實際值。
