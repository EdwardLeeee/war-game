# Brief：R8 寫實畫風整套（版本 2）— war-game-ui

ceo 2026-10-21。依據：`docs/decisions/log.md` D-092、D-093。

## 背景

- 使用者看過 R7 四個版本，原話：「弓箭手要拿弓箭 不是十字努 版本二比較好」。
- 要不要花錢，原話：「就是麻煩你設計，你做得到」。不花錢，交給我們做。
- 東陸、西陸的遠程兵都改拿弓（使用者選「東西陸都拿弓」）。
- 目標還是 D-092 的「寫實細緻、完全寫實比例」。使用者的標準是星海爭霸、世紀帝國，請照這個標準要求自己。

## 範圍

照 R7 版本 2 的做法，做整套。每一項先出核准稿，使用者核准後才量產成 art-v6。

1. **兵（12 種，東西陸）**：

   | 兵種 | 東陸 | 西陸 |
   |---|---|---|
   | 村民 | 農夫 | 村民 |
   | 槍兵 | 槍兵 | 長矛兵 |
   | 遠程 | 弓手（新，拿弓） | 長弓兵 |
   | 騎兵 | 具裝騎兵 | 騎士 |
   | 攻城 | 霹靂車 | 投石機 |
   | 法師 | 術士 | 晶術師 |

   - 人體用 MPFB（CC0），盔甲、衣服、武器貼身，材質用 CC0 PBR。
   - 動作沿用核准過的關節角度，重新對到新骨架。弓手要有拉弓、放箭的動作。
   - 馬：找授權允許商用的寫實馬。找不到就沿用現在的馬，換上寫實材質。
   - 法師的法器、防護罩、晶砲效果，和寫實畫風要搭。
2. **建築**：東西陸全部建築，含施工中、受損、廢墟。倒角、石縫、木紋、瓦、茅草、髒污。
3. **城牆**：小鎮木柵、大城石牆（D-089）。
4. **資源點**：樹、金礦、晶脈、野果。
5. **地形**：石堆、岩脊、懸崖、水岸、淺灘、橋。
   - 懸崖不能看起來像城牆（ceo 看 #251 時發現遠看很像），要一眼分得出是天然的岩壁。
6. **地面**：寫實的草、土、碎石、河岸混合，接縫自然。隨機地圖要能鋪，實際大小下看不出重複。
   - 這要 client 改地面的畫法，格式請直接和 war-game-client 對。

## 好不好認（一定要過）

R7 發現寫實地面上的兵比較難找。核准稿要證明下面三點都做得到：
- **找得到兵**：兵和地面的明暗要拉開。可以用玩家色的布包住身體前面和兩側（不要只做一片平的前片），加輪廓光。
- **分得出東西陸、兵種**：東西陸的遠程兵都拿弓以後，要靠服裝和盔甲分。
- **敵我一眼看出**：同文化兩隊對上時，藍紅一眼分得出來。

每張核准稿都放實際大小（31 pt）和手機 3 倍，也要有同文化藍紅對上的畫面。

## 規則

- **不花錢、不開帳號**。外部素材先讀官方授權原文，記在 THIRD_PARTY_NOTICES.md；只用可商用、可以算成圖片出貨的。
- **原創**：不照抄任何遊戲的造型。
- **檔案**：外部素材的原始檔不進 repo，CI 照網址下載、核對 sha256。
- **記憶體**：手機用 2 倍 ASTC。量出每一類圖集的記憶體，和 art-v5 比。
- **核准稿**的檔名照慣例（`R8-<編號>-<項目>-<東陸|西陸>-mobile.png`），另加總覽。動作附 GIF。

## 順序

1. 先回 ceo 計畫和時間估計，核准後開工。
2. 核准稿分兩批給使用者看：
   - 第一批：12 種兵；
   - 第二批：建築、城牆、資源點、地形、地面。
3. 使用者核准後，量產成 art-v6，從 main 發 Release，核對 sha256 後通知 client。
4. art-v6 不改模擬，存檔不會斷。
