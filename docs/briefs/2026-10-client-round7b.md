主旨：war-game-client 做第七輪第二部分的畫面：城鎮只能搶一次和治理收入、箭樓、遠程兵和法師躲進建築、馬廄和騎兵。依據是使用者 2026-10-07 的回饋（D-061）和 war-game-core 的第七輪協定（PR P）。

## 目標

- 玩家看得出哪座城已經被搶過、治理現在收入幾成。
- 玩家能蓋箭樓、把遠程兵和法師躲進主城或箭樓、再叫他們出來。
- 玩家能蓋馬廄、出騎兵，騎兵和其他兵一樣能編隊、下指令。

## 依據

- 使用者原話與選擇：`docs/decisions/log.md` 的 D-061（含補充）。
- 規則和協定：`docs/briefs/2026-10-core-round7.md`；core 的 PR P（`sim/PROTOCOL.md` 第七輪那幾節）。協定草案的重點：
  - 新兵種 `UnitType.Cavalry`，新建築 `BuildingType.ArrowTower`、`Stable`。
  - 指令 `garrison`（遠程兵、法師躲進自己的主城或箭樓）、`leave`（出來）。躲著的兵 `order` 是 `Garrison`，`orderTarget` 是建築。
  - 快照：建築的 `soldiers`（自己建築裡的士兵數）、`BuildingFlag.Occupied`（裡面有人，敵我都給）、`PlaceBit.TowerLand`（可以蓋箭樓的格子）。
  - 城鎮的 `incomePermille`（治理收入幾成）、`TownFlag.Plundered`（這局被搶過）。
  - 事件 `shot`：主城、箭樓和躲著的兵射一次發一個，用來畫箭。
  - 拒絕原因 `AlreadyPlundered`、`NoRoom`。
  - 以 PR P 合併後的 `PROTOCOL.md` 為準；和這裡不一樣時照 PROTOCOL.md，並在 PR 描述寫出來。
- 敵方建築只看得到「有人躲著」，看不到幾名（D-061 補充）。

## 範圍

### 要改（`client/`）

1. **城鎮**
   - 被搶過的城鎮，攻下時只出現「治理」，並寫一句「這座城這局已經被搶過，只能治理」。
   - 治理中的城鎮面板顯示收入幾成，回升中時寫「收入 40%，慢慢回升」之類。
   - 開局提示和選單裡講城鎮的說明，改成「每座城一局只能搶一次」。
2. **箭樓**
   - 建造選單加箭樓；只有 TowerLand 的格子能放，放不下時說明「要在主城或治理的城鎮附近」。
   - 箭樓的圖形照原型的幾何做法，和大城的箭樓分得出來。
   - 用 `shot` 事件畫箭（主城、大城箭樓、玩家的箭樓、躲著的兵），畫法你定，要看得出是從建築射出來的。
3. **躲進建築**
   - 選了兵以後，指令區有「躲進去」：接著點自己的主城或箭樓。沒有遠程兵或法師時不出現，或按了說明「只有遠程兵和法師能躲」。
   - 點自己的主城或箭樓：面板顯示裡面有幾名士兵、有「全部出來」。
   - 建築上用小記號顯示「裡面有人」（Occupied），自己的和看得到的敵方建築都要。
   - 躲著的兵不會出現在戰場上；編隊、軍團畫面怎麼算他們，你定，寫在 PR 描述。
4. **馬廄和騎兵**
   - 建造選單加馬廄；馬廄面板訓練騎兵，自動訓練的開關照兵營。
   - 騎兵的圖形照原型的幾何做法，和槍兵分得出來。
   - 軍團畫面多一列騎兵；編隊、全軍、人口、選取資訊都要算到騎兵。
5. **說明**：選單裡的兵種說明加騎兵（剋法師和遠程兵、被槍兵剋）。

### 不做

- 規則本身：war-game-core。電腦：war-game-ai。
- 正式介面和正式美術：第三階段。原型的介面照前幾輪的做法，不先出設計稿。

## 限制

- 等 core 的 PR P 合併後再開始；做到一半協定有變，以 main 的 PROTOCOL.md 為準。
- 公開 repo：不放金鑰、個資或真實姓名。
- 本機只跑相關的測試；重工作用 `systemd-run --user --scope -q -p MemoryMax=1500M -p MemorySwapMax=0` 包起來，available 低於 2000 MB 就等。
- 合併時機由 ceo 決定：和 core 的 T、D、K、war-game-ai 的改動一起上線。
- 使用者指示（2026-10-03）：你自己 terminal 每個回合的結尾文字一行就好；給 ceo 的訊息只在三種時候傳：計畫要核准、PR 好了、需要決定的事。

2. 可以分幾個 PR；每個好了回報連結、CI 結果和截圖。
