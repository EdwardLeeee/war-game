## 重畫

```bash
cd sim && node src/map-samples.ts ../docs/research/2026-10-random-maps/maps.json 129
cd ../docs/research/2026-10-random-maps && python3 render.py maps.json .
```

`map-samples.ts` 輸出前會檢查每張圖：每一格和它的鏡像一樣；用兩方的 frame 換到標準座標後，地形、資源、主城、城鎮都一樣。箭樓另外列出偏了幾格。

## 產生器（`sim/src/core/random-map.ts`）

- 邊長一定是奇數（「128」做成 129），中線才會剛好是一整欄，軸上城鎮的中心到雙方完全一樣遠。
- 對角或相鄰各一半機率；只在玩家 0 那一半產生，再鏡射到另一半；最後整張圖隨機轉向或翻面（8 種）。
- 7 座城鎮：軸上 1 座大城，每方 3 座小鎮（家旁 26–34 格、第二座 45–60 格、另一座離主城 40 格以上），城鎮中心彼此至少 20 格。
- 家附近的資源照固定地圖的樣板；第二座金礦在往家旁小鎮的半路旁邊；第二座小鎮旁 8–10 格一座金礦，第三座小鎮一半機率也有。
- 晶脈在軸上、離大城 14–24 格：對角是 2×2，相鄰是 1×4（2×2 沒辦法在一欄寬的軸上左右對稱）。
- 先留 3 格寬的通道再撒岩石和森林；走不到的空地變岩石，城鎮和資源走不到就重來，最後一次不撒岩石和森林。
- 種子 1–300、邊長 97／113／129 都產生成功，每張約 3–4 毫秒。

## 已知的不對稱

- 相鄰出生時，大城的箭樓（2×2）沒辦法剛好在一欄寬的中線上，會往一邊偏一格，偏哪邊由種子決定。
- 相鄰出生時，小鎮的 6 名民兵站位（`scenarios.ts` 的 `POSTS` 前 6 個）不是左右對稱；第三步要讓隨機地圖的站位跟著鏡射。
