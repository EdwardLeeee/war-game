## 檔案

- `2026-11-examiners/examiners.json`：三個考官，每個有：
  - 種類、地圖；
  - 搜尋、第一次驗證、重驗的 run 和勝場；
  - `base`：打法的基底（策略／速度／陣形）；
  - `set`：在基底上改了哪些欄位；
  - `plan`：完整的打法（含 `tune`）。
- `2026-11-examiners/checks/<run>/<job>/`：三次驗證每個 job 的 `summary.md` 和 `examiners.json`（每個打法的逐局結果）。
  - 43804939019：第一輪，驗了 11 個打法；
  - 44569272785：第二輪，驗了 2 個；
  - 44809691007：重驗。

## 怎麼重現

用 core 的腳本對局程式（`sim/src/scripted-games.ts`）：
- 把 `examiners.json` 裡那個考官的 `plan`（完整的打法）存成一個檔，交給 `--plan`。
- 不要用 `set`：它的欄位名稱是 `tune.turtle.max` 這種點號寫法，`--plan` 要的是巢狀的 JSON。
- 策略／速度／陣形照 `base` 寫。

以 10-79 為例，基底是 `push/h1/all`：

```sh
cd sim
node src/scripted-games.ts --strategy push --speed h1 --formation all \
  --plan 10-79.json --difficulty hard --map random --cap 90 \
  --seeds 8000001-8000200 --json out.json
```

已經驗證過可以精確重現：在 main `6768be0b` 上（遊戲程式和 254a644d 相同）照上面跑種子 8000001，結果是贏、第 23066 tick 結束、最後雜湊 `8c3362e0`，和重驗那局一模一樣。

訓練程式直接用 `plan`，和驗證時一樣。

## 限制

- 考官只會腳本玩家會的招。使用者用新招贏了，要先請 core 把那招加進腳本玩家，搜尋才找得到。
- 規則或腳本玩家一改，考官就要用新種子重驗。使用者還沒玩過 #525；如果要改這條規則，考官要再驗，訓練也要重來。
- 困難每升級一次，考官要針對新版再找一次（計畫 4.1）。舊考官留著，新版不能輸回去。
