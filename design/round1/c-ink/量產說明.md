# R1-01-畫面風格-C-水墨戰卷-量產說明

水墨戰卷｜和 B 共用 3D 模型，畫成濃淡墨＋毛筆輪廓，合成在宣紙上｜紙白墨黑、只有玩家色與魔法上色（高反差）｜工時是 AI session 的作業時間，不含使用者審稿

## 工具鏈

- 和 B 共用同一套 Blender 模型、動作、8 方向（B 的建模工時不必再付一次）。
- 每格算 4 層：顏色、光影（白模）、玩家色遮罩、影子。
- Python 把顏色換成濃淡墨（紙白到墨黑），光影壓成 3 階，內側加暈染聚墨，外輪廓是粗細不一、帶飛白的毛筆線；只有玩家色與魔晶保留顏色。
- 地面：程式產生宣紙、淡墨暈染、毛筆描邊與草葉筆觸；畫面上方留白成霧，四角淡墨。

## 引擎需求

- 執行時只畫 2D 圖，不需要即時 3D；墨線與色階都已烤進圖裡。
- 畫面多一層全螢幕的宣紙紋理與黃昏暗角（一張疊加圖，負擔很小）。
- 玩家色：遮罩＋換色，同 B。

- 3 倍未壓縮放不進手機記憶體；建議 2 倍＋ASTC 壓縮（約 40 MB 級）。
- 算法：影格數 × 平均修邊面積（本輪實測兵種 140×136 px、建築約 24 萬 px，3 倍）× 每像素位元。
- 只載入這一局出現的文化；遮罩也可以塞進同一張圖的一個通道。

## 可以商用的確認

- Blender 5.2.2（GPL）：只當製作工具；GPL 不管算出來的圖，圖可以商用。
- Python、Pillow、numpy、pycairo、ffmpeg、pyoxipng（MIT）：製作工具，不隨遊戲發佈。
- Google Chrome：只用來把設計稿的 UI 截圖，不進遊戲。
- Noto Sans／Serif CJK TC（SIL OFL 1.1）：設計稿文字；遊戲若內嵌字型，OFL 允許商用與內嵌。
- 模型、材質、徽章、地面全部由本 repo 的程式產生，沒有使用第三方素材。

## 東西兩套放在同一個戰場：評估

- （通過） 和 B 明顯不同：宣紙留白、濃淡墨、毛筆輪廓，只有玩家色與魔法上色。
- （通過） 墨線把兩邊的材質統一成同一種筆觸；西陸石塔、騎士畫成墨線不怪，和東陸城樓放在一起一致。
- （通過） 玩家色與魔晶青光在黑白畫面上最跳：敵我與魔法是三個選項裡最清楚的。
- （問題） 水墨效果還不到位：單位的濃淡變化偏平，比較像「墨線插畫」；真正的筆意與暈染層次要第 2 輪再加強。
- （問題） 水墨本身帶東方印象，西陸的「西方感」被沖淡，石塔與騎士像「東方畫師筆下的西洋兵」。
- （備註） 原本偏暗，依 ceo 回饋改成紙白墨黑；三個選項目前沒有真正偏暗的版本。
