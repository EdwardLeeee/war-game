# R16 種田農民的鋤頭和動作

使用者 2026-11-10：「種田的農民圖看起來好像有點怪」。選擇欄位選了「鋤頭太大太白」「動作怪」，另外打了「手拿鋤頭感覺不太符合真實拿法」。
brief：`docs/briefs/2026-11-ui-farmer-hoe.md`。

## 程式改了什麼（`design/production/blender/anims.py`）

- **鋤頭** `_hoe()`：暗色舊鐵（`iron_e`／`iron_w`，寫實畫法裡對到 `rusty_metal_02`），刃口一條磨亮的細線；刃和柄夾 70 度，刃口朝人。
  - 東陸：钁鋤（王禎《農書》卷十三）。方頭，柄穿過鐵頭、上面露 2 公分，刃口平直。
  - 西陸：上方鐵環套柄，刃往下變寬（羅馬到中古的 Erdhaue 實物）。
  - `R16_HOE_SCALE`：1.0 是 A 真實大小，1.5 是 B。art-v7.7 的鋤頭是 34×40 公分的兵器鋼（`P["steel"]`，寫實畫法裡對到亮的 `metal_plate`）。
- **種田** `_farm_keys()`：8 格，第 3 格入土（hit 照舊）。
  - 兩手握柄：左手柄尾，右手在前面、沿柄滑。
  - 舉到胸口到頭的高度，刃往下垂；刃口先入土，落在前腳前方約 1 公尺；往腳邊拉 25–30 公分，再舉起。
- **西陸農民平常拿鋤頭** `carry_hoe()`（待機、走路）：右手垂在身側握柄中段，鋤頭頭朝下在右腳旁，刃離地；左手也垂下，走路時擺動。
  - 改前是握柄尾、柄往前伸、刃平放在遠處地上。
  - R8 的 `CARRY["hoe"]`（`design/r8/blender/r8.py`）只在 `R16_OLD=1` 時用到。
- **西陸攻擊** `HOE_ATTACK`：10 格，第 7 格打中（和改前一樣）。兩手握柄，舉過右肩往前劈下。
- **倒下**：程式不用改。原本的 `DROPS["farmer_w"]` 和 `settle()` 會讓新鋤頭鬆手，刃側著、柄尾著地，躺在身旁。
- `R16_OLD=1`：畫回 art-v7.7 的鋤頭、動作和拿法，用來做改前的圖。
