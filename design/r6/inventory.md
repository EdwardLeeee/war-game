## 0. 怎麼讀這份表

- **暫定編號** INV-01 起，照畫面由上到下、由左到右的順序排，一個元件的每一種狀態各佔一列。
- **大小與位置**：寫 CSS 的寫法，再換算成 814×380、安全區為 0 時的實際 px（`client/docs/screens/` 的截圖就是這個條件）。`safe-t/r/b/l` 是 iPhone 安全區的內縮。
- **觸控大小**：`style.css:46-57` 讓**每一顆** `button` 至少 44×44（`--touch: 44px`）。我逐一查過，**沒有任何可以點的東西小於 44 px**。剛好 44 的有：✕、−／+、退1–退4、各種一般按鈕的高度。比 44 小的只有不能點的東西：資源列（約 36 高，`pointer-events: none`）、血條（5 px）、快轉進度條（12 px）。
- **檔案**：寫建立它的地方，格式是 `路徑:行`。不在 `client/src/ui/` 裡的，會寫完整路徑並註明「不在 ui/」。
- **截圖**：`client/docs/screens/` 的檔名，省掉前面的 `2026-10-` 和後面的 `-814x380.png`。只寫「無」的，就是還沒有截圖（第 13 節整理了怎麼截）。標「過時」的截圖拍的是舊版介面，**那個部分不要照著畫**。
- **全域觀察**：
  - `style.css` 沒有任何 `:active`、`:hover`、`:focus` 樣式，也沒有任何 `transition`。按下去時畫面不會變（只有瀏覽器預設的反應）。所以「按下」狀態要由設計稿重新定義。
  - 「亮著」的狀態只有一種畫法：`button.active` 加 3 px `#fff3b0` 外框（`style.css:619-621`）。
  - 「主要／次要」按鈕：預設是 accent 金色 `#e7c35a`、字 `#1b1a17`；加上 `.secondary` 變灰 `#cfd6d2`。
  - 字型：全頁 `15px/1.4 -apple-system, "Noto Sans TC", sans-serif`（`style.css:31`），按鈕 600 字重。正式版要確認字型可以商用，寫進 `THIRD_PARTY_NOTICES.md`（brief 要求）。

## 12. 「重設」是什麼

**位置**：左欄最上面，淡黃色 `#fff3b0` 的「重設」（INV-35）。`hud.ts:102-103` 建立，點了呼叫 `game.reset()`。

**程式做的事**（`client/src/game/game.ts:1675-1687`，不在 ui/）：

```ts
reset(): void {
  this.setMode("normal");                         // 離開「選位置」狀態
  if (this.placement !== null) this.endPlacement(); // 收掉建築預覽和 ✓ ✗
  this.overlays.closeWheel();                     // 關掉輪盤
  this.apply([{ kind: "clear" }]);                // 取消選取（軍團畫面也一起關）
  this.hud.closePanels();                         // 關對話框（勝負畫面除外），指令區回第一頁
  if (!this.lab.busy) this.lab.hide();            // 沒在量測就關量測面板
}
```

- `setMode("normal")`（`game.ts:1607-1610`）：離開進攻、撤退、晶砲、集結點、躲進去、駐守這六種「點地面選位置」的狀態，提示列一起收掉。
- `apply([{kind:"clear"}])`（`game.ts:1449-1490`）：清掉選取和「點了在看的東西」，選取資訊隱藏，軍團畫面關閉（`groupView = null`）。
- `hud.closePanels()`（`hud.ts:481-485`）：對話框開著、而且不是勝負畫面時關掉；`cmds.reset()`（`panels.ts:818-821`）讓指令區離開建造選單、回第一頁。
- 它**只改畫面，不改戰局**：不會叫兵停下、不會取消訓練、不會改姿態。收起狀態（INV-47）也不會被打開。

**白話**：重設是「回到什麼都沒選的畫面」的一鍵。手指點錯、卡在「請點地面」的狀態、開了建造選單不想蓋時，按它就回到乾淨的畫面。它跟選取資訊角落的 ✕ 不一樣：✕ 只取消選取，不會離開選位置的狀態、也不會收掉建築預覽。

**由來**：D-024，使用者原話「取消選取有點慢，能不能有個按鈕點一下就可以回到預設？」。ceo 當時的解讀是做一顆固定在畫面上的重設鈕（log 裡也註明「使用者如果指的是別的問題，再修正」）。D-025 更正範圍：對話框開著時有全畫面暗底，**根本按不到重設**，所以實際上它關不到對話框（程式還是寫了 `closePanels`，但手指碰不到）。GDD 第 10 節第 342、392–399 行有完整範圍。

**對設計的意思**：它是「離開目前狀態」的萬用鍵，和 ✕、提示列的「取消」、建造選單的「返回」功能重疊。使用者說左邊的按鈕「幾乎用不到」，可以考慮的收法：併到 ✕ 或提示列的「取消」、只在有東西可以重設時才出現、或收進選單。這些要畫成選項給使用者挑（brief B 節）。
