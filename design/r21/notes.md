# R21 攻城砲（R19 第 6、7 項）— 出處筆記（還沒開始做）

- 《武經總要》前集卷十二（zh.wikisource，2026-11-11 查）：
  - 單梢砲「四十人拽，一人定放。放五十步外，石重二斤」；雙梢砲百人拽；五梢砲百五十七人拽；七梢砲二百五十人拽、二人定放。
  - 旋風砲「五十人拽，一人定放」；虎蹲砲「七十人拽，一人定放」。
  - 手砲「敵近則用之……用二人放，石重半斤」。
  - 炮車「大木為床，下施四輪，上建獨竿」，「其施放及用物一準常炮法」：東陸現在的四輪砲車對得上這一種。
- 配重砲的輪子：圖像裡帶輪子的底架少見但有（Russell Miners 的插圖整理：也可能用滑橇底架拖到定位再固定）；NOVA 的重建認為輪子能吸收發射時的晃動，小型的可以推著走。大型的是拆開運、到了再組。
- 程式：東陸的四條拉繩 `siege_e_pull{k}` 掛在 base 上、不跟砲桿動（`design/round5/blender/roster5.py`）；動作在 `anims.extend_siege`。西陸 `west_r8.dress_siege` 是固定木架，`spec.STRIDE_M["siege_w"]` 還是舊輪子的數字。

- `anims.extend_siege`：走路只轉 `<kind>_w{-1,1}{a,b}` 四個輪子（`SPIN_PER_CYCLE` 90 度）；西陸的輪子在 R8 換成固定木架時被藏起來，所以走路 8 格相同。攻擊走 `inner`（R5 的動作）。倒下：`collapse_e`／`collapse_w`，東陸的拉繩 `pull{k}` 在裡面鬆掉、倒下。
- 東陸選項：
  - A 只動繩子：拉繩的上端改跟砲桿短端走，下端（握把）在發射那幾格往下往後拉、再彈回。只改 `extend_siege` 的攻擊。
