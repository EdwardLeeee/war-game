## 怎麼做的

- `blender/kit.py`：東西陸兩套材質與零件（牆身、屋頂、布幔、旗、道具）。大小都從「格數 × 每格公尺數（`CELL`）」算，1 格 = 2 公尺之後改了只要重算。
  - 磚紋、石紋沿 (x + y, z) 展開：鏡頭看得到的 -X、-Y 兩面都有一層層的石頭（lib 原本的貼法在 -X 面會糊成一條）。
- `blender/blds.py`、`blds2.py`：15 種建築，各有東西陸兩種。
- `blender/states.py`：B1-02 的狀態，從完成的模型做：布林切割、鷹架、木架、破洞、瓦礫、焦黑。屋頂這種有厚度修改器的薄面用網格直接切（布林在它上面會整片消失）。
- `blender/towns.py`：城鎮的一塊一塊：民房（2×2、2×1、1×2）、大城箭樓、旗、界樁、搶與修繕的道具、廣場與街道的鋪面。
- `blender/nature.py`：資源點，一格一塊。
- `blender/render_b1.py`：每塊在新的場景裡建、算本體、玩家色遮罩、影子（半解析度）、環境光遮蔽，寫出錨點與占地；`probe` 做遮擋量測。
- `common/run.py`：把要算的東西分成 CI 的工作（`TARGETS`），算完把 2 倍超取樣縮回 3 倍。
- `common/scene.py`：照遊戲的畫法合成（影子先畫在地面，再依占地前後排序）。
- `common/smoke2d.py`：煙是 2D 疊圖（像落地揚塵），模型只記冒煙的位置。
- `common/layouts.py`、`layout_art.py`、`town_art.py`：城鎮配置與合成。
- `common/b1art.py`：全部設計稿；`common/memory_b1.py`：記憶體。

```bash
# 算圖（CI）
gh workflow run design-render --ref <分支> -f round=b1 \
  -f targets='["core3","states_main_city","states_house","states_barracks","towns_E","towns_W","b101_E","b101_W","b104"]'
# 下載後合成
python3 common/b1art.py b102 b103 b101 b104 --suffix x3
python3 common/layout_art.py x3
python3 common/memory_b1.py x3
```

本機只在 available ≥ 2 GB 時跑小預覽（`run.py <target> --preview --ppm 24`），一樣在 1.5 GB 上限區裡跑。

## 遮擋量測（擋人）

- `render_b1.py` 的 `probe`：在建築兩面背牆（+x、+y）外面每一格、加上斜後角，放一名 1.8 公尺的士兵，從他身上往鏡頭射視線（橫向三條，兩條沒碰到建築才算看得到），量他露出幾公尺；距離從緊鄰的 1 格量到 5 格。

## 給 client 的說明（和兵種圖集第 2 版不同的地方）

這一輪不出量產圖集，只先定好做法：

1. **方向**：建築、城鎮零件、資源點都只有 1 個方向，不鏡像（地圖格子固定，建築不轉向）。城牆直段與城門有沿 x、沿 y 兩張；城牆轉角是一座角樓，四種轉角和牆的端點都用同一張。
2. **錨點**：占地的中心點（在地面上）。說明檔另外寫占地 `footprint`（格數），client 可以算出占地的四個角。
3. **前後順序**：兵種圖集第 6 節是依錨點的 y 排序。大建築只用一個點排，站在它旁邊的單位會一下在前、一下在後。建議：
   - 建築 A 要畫在 B 前面，條件是 A 的占地整個在 B 的 x 較小一側，或整個在 y 較小一側（鏡頭朝 +x、+y 看）；其餘依占地中心排；
   - 單位當成一個點，和建築用同一個規則比；
   - 這一輪所有設計稿都是照這個規則合成的（`common/scene.py`）。
4. **城鎮和城牆是一塊一塊的**：每棟民房、每段城牆各是一張圖、各自排序，部隊才能站在房子之間。城鎮的廣場與街道鋪面（`tground`）只是暫時的示意，正式由 B2 的地形負責。
5. **地面層**：農田（可以走過去）和採完的資源格畫在地面層，比所有單位先畫；作物不高於 0.6 公尺，不會擋人。
6. **圖層**：顏色、玩家色、影子（半解析度、黑色加透明度）同兵種；建築沒有特效層。
7. **煙和火**：煙是疊圖，由遊戲畫在建築上面（位置寫在說明檔的 `smoke`），之後可以做動畫；受損時的火焰目前畫在建築圖裡。共用疊圖的做法見記憶體一節。
8. **狀態怎麼換圖**：看使用者選哪一種、ceo 選哪一種製作方式再定；兩種都可以：
   - 每棟各自畫：每棟建築多幾張圖（施工中 3 張、受損 1 張、被摧毀 1 張）；
