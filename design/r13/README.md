# R13 輪：合成一個「進駐」、局後統計

- 主題：D-124（使用者 2026-11-04 看了 38 局的按鈕用量後選的兩項；ceo 2026-11-04 派工）。這輪只出設計稿給使用者挑，不改 client。
  - **R13-01 進駐**：「駐軍（進城）」「躲進去（主城、箭樓）」「駐守（哨所）」三顆合成一顆「進駐」。選兵後按進駐，再點自己的城、主城、箭樓或哨所，由那棟決定誰進去：城＝整個編隊進城守（遠程、法師上牆，其他在城內）；主城、箭樓＝遠程、法師躲進去；哨所＝槍兵躲進去。村民的「全體回城」不動；建築上的「＋遠程」「＋法師」「＋槍兵」照留（叫最近的）。

### B2 的做法

規則寫在看板上（`compose.py` 的 `B2_RULES`）。`common/r13-tags.js` 的 `placeTags`、`edgeArrows` 是不碰畫面的純函式，輸入建築和介面的方框、輸出標籤和箭頭的方框；看板就是它們算出來的，client 可以直接照著做。數字（14、72、150、70 pt）是在這幾個畫面調出來的，實機覺得不對可以調，規則不變。

## 做法與數字的根據

- **戰場底圖**（`field.py`）：art-v7 的寫實戰場（R11 s4 的 `river_d`、`grass_d`，`v7board/west_fall`）；建築是 art-v7 看板（V7B-01、V7B-03）的格子和 art-v6.4 的 3×3 哨所，羽化貼上、草地調成底圖的顏色。為了一張圖看到四種建築，鏡頭拉遠（約 0.42 倍）、建築擺得比實際近，這是示意。哨所是方形斜看（3×3 還沒有菱形圖），其他是菱形。
- **進駐的文案（R13 新提的）**：指令鈕「進駐／點建築」，選建築時「取消／進駐」；提示列 A「點亮起來的建築：選的兵進去守（誰進去寫在下面）」、B「點亮起來的建築：標籤寫誰進去、誰留下」；滿了「箭樓滿了（最多 3 名），沒有人進去」（照 `callFullText`）；點錯「要點亮起來的建築：自己蓋好的城、主城、箭樓或哨所」（照 `GARRISON_WRONG_TARGET` 的句型）；空位不夠時「最近的 N 名進去」（照「叫兵進去以最近的為主」）。
- **建築面板的按鈕名（提議，請使用者確認）**：主城、箭樓的「全部出來」和哨所的「全部離開」統一叫「全部離開」；哨所面板每個編隊的「歸隊」改叫「召回」（和軍團畫面同一個字）。城的面板照舊「歸隊」「全部帶走」。軍團畫面三顆照 main：召回（叫躲在主城、箭樓、哨所的出來）、出城歸隊（城裡留最少人數）、全部帶走。編隊鈕的駐N、躲N 照舊分開（使用者 2026-10-26「分開顯示」）。
- **統計的假資料**（`r13-stats.js`）：勝局 26:40（對困難・掠奪型，雙河關）、敗局 23:15（對困難・均衡型，固定地圖）。成本、法師上限 6、搶一次拿糧金魔晶、治理修繕 45／60 秒、廢墟 4 分照 sim 和 GDD。人口：brief 寫上限 120，但 main 的 `POPULATION_200.on = true`（基本 200，加民居、治理的城）；假資料士兵最多 58／71 名、村民約 45 名，兩種上限下都合理。
- **圖表顏色**：我方 #2e6ed6、敵方 #c8302c（`design/b1/common/config.py` 的隊色），卡片底 #221810。`validate_palette.js "#2e6ed6,#c8302c" --mode dark --surface "#221810"`：亮度、彩度、色盲（protan ΔE 26.1）、一般視覺（ΔE 32.5）、對比都過。不只靠顏色：我方實線＋圓點、敵方虛線＋方點，圖例一直在，線尾直接寫「我方 11,734」；擊殺與損失用左右位置分（左我方損失、右我方擊殺）並寫數字；城鎮時間軸在色塊裡寫「我方治理」「敵方治理」「廢墟」，事件用「治」「搶」「叛」字圈；格線是 1 px 實線；每張圖都有表（雙方數字）可以對照。

## 量測（每格下面印出來）

- 觸控目標：每格的按鈕都 ≥ 44 pt（`shoot.mjs` 量每顆看得到的按鈕）。
- 指令區：現況 3 排、A／B 合成後 2 排。
- 截字、超出畫面、面板互相蓋住：沒有。編隊面板（狀態 8）刻意在下緣切掉，表示往下捲。

## 還不夠好的地方

- 戰場是示意：建築靠得很近、比例是拉遠的；實際上城鎮離主城約 20 格，一個畫面通常看不到四種，畫面外的建築這兩個選項都沒有提示。
- A 的選取資訊（171 pt 高）蓋住戰場下半，亮起來的建築要在上半才看得到；B 的標籤會蓋住建築本身，建築擠在一起時標籤可能疊在一起（這張沒疊，但沒量過更擠的情況）。
- 面板比 R6 的選取資訊（171 pt）高：A 的進駐清單 178 pt、哨所面板（7b）約 225 pt、軍團畫面 236 pt，往上長到戰場中間。
- 軍團畫面（8）五個兵種的 −／＋ 放不下，要往下捲；A、B 都一樣。
- 局後統計的「晶砲擊殺」「關鍵時刻」「城鎮易手」現在 sim 沒有記，資料要 client 或 core 另外記（D-124 寫明實作前要回計畫）。
